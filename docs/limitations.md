# Реєстр обмежень Super Loop (ЛР3)

### Обмеження №1: Затримка реакції при тривалих операціях камери та Flash[cite: 5, 15]
* **Симптом:** Під час захоплення кадру або стирання Flash затримується обробка подій від датчиків[cite: 5, 15].
* **Доказ:** Під час тесту S3 максимальна затримка `event_latency` зростає з десятків мікросекунд до десятків мілісекунд[cite: 7, 14].
* **Причина в архітектурі:** Відсутність витіснення (preemption). Термінова задача змушена чекати завершення поточного ітерації циклу[cite: 5].
* **Що могла б дати ОС:** Розділення задач на окремі потоки з пріоритетами, витіснення тривалих задач високопріоритетними[cite: 15].

### Обмеження №2: Джитер (Jitter) періодичного опитування сенсорів[cite: 8, 15]
* **Симптом:** Інтервал між запусками `Task_Sensors` коливається залежно від навантаження CLI та FSM[cite: 8, 15].
* **Доказ:** Виміряний джитер зростає при виконанні сценарію S3[cite: 8, 14].
* **Що могла б дати ОС:** Апаратні/програмні таймери FreeRTOS з фіксованим періодом квантування[cite: 15].
